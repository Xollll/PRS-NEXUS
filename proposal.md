# Project Proposal: SiswaSphere

## Introduction
SiswaSphere is a web-based student organization management system built with Laravel. It is designed to centralize the administration of members, committee positions, meetings, and activities in one platform. The system provides both a public-facing directory for quick information lookup and an admin interface for maintaining organizational records.

## Problem Statement
Student organizations often rely on scattered spreadsheets, manual documents, and informal communication to manage their internal records. This creates several issues:

- Member information is difficult to keep updated and consistent.
- Committee structures are not easy to track over time.
- Meeting records and activity schedules can be lost or duplicated.
- Searching for specific student, committee, or meeting information takes too much time.
- Administrative tasks depend heavily on manual work, which increases the risk of errors.

SiswaSphere addresses these problems by providing a single system for storing, searching, and managing organizational data.

## Objectives
The main objectives of this project are to:

- Develop a centralized system for managing student organization records.
- Provide a public directory for searching members, committee positions, and meetings.
- Allow administrators to create, update, and delete organizational data efficiently.
- Improve data accuracy and reduce dependence on manual record keeping.
- Make information easier to access for both admins and general users.

## Scope of the Project
This project focuses on the core administrative and informational needs of a student organization. The scope includes:

- Public home page with overview statistics and recent records.
- Searchable public directory for members, committee positions, meetings, and activities.
- Admin login and session-based access control.
- Member management, including create, view, update, and delete functions.
- Committee position management.
- Meeting record management.
- Activity record management.
- Basic dashboard view for administrators.

The project does not cover advanced features such as automated notifications, mobile applications, payment processing, or full role-based approval workflows.

## System Features
SiswaSphere includes the following features:

- Public homepage that presents system overview and recent records.
- Directory search that allows users to filter information by name, role, meeting title, or location.
- Admin authentication for secure access to management functions.
- Member management module for storing student details such as name, matric number, email, phone number, programme, role title, and status.
- Committee management module for organizing titles, categories, display order, and descriptions.
- Meeting management module for storing meeting titles, dates, locations, and summaries.
- Activity management module for tracking planned, ongoing, and completed activities.
- Dashboard summary showing counts and recent entries for quick monitoring.

## Users
The system is intended for the following users:

- Admin users: Manage all system records, maintain data accuracy, and control access to the admin area.
- Organization members: View directory information, committee structure, meetings, and activities.
- General visitors: Access the public homepage and directory for basic organizational information.

## Conclusion
SiswaSphere is proposed as a centralized solution for managing student organization information in a more structured and efficient way. By combining a public directory with an administrative backend, the system improves accessibility, organization, and record keeping for the entire student group.
